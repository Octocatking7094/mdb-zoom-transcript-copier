# Zoom Transcript Copier  
  
A simple Chrome extension that adds a “Copy Transcript to Clipboard” button to Zoom cloud recordings, making it easy to extract and use meeting transcripts.  
  
## Features  
  
- Injects a button into Zoom recording pages with transcripts  
- Copies the entire transcript as plain text to your clipboard with one click  
- Easy to use and lightweight – no external dependencies  
  
## Installation  
  
1. **Download this repository (Code → Download ZIP) and unzip it.**  
2. In Chrome, go to `chrome://extensions`  
3. Enable **Developer mode** (top right).  
4. Click **Load unpacked** and select the unzipped folder.  
  
## Usage  
  
1. Go to your Zoom recording page with a transcript.  
2. If prompted, enter your recording password as usual.  
3. Once the transcript appears, click **Copy Transcript to Clipboard** (button will appear in the top right).  
4. The full transcript will be copied to your clipboard, ready to paste anywhere!
